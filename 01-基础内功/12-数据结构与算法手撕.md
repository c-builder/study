# 数据结构与算法手撕

## 学习目标

- 掌握大厂前端架构师面试高频算法题型与解题模板
- 能分析时间/空间复杂度并说明 trade-off
- 能在白板/IDE 中 20-40 分钟内完成中等难度题

## 为什么需要

字节、阿里、腾讯架构师面试几乎必考算法（字节尤其严格）。架构师不是纯算法岗，但考察的是：**抽象问题能力、代码质量、复杂度意识**——这些直接体现在技术方案设计中。

## 一、复杂度速查

| 符号 | 含义 | 典型场景 |
|------|------|---------|
| O(1) | 常数 | 哈希查找、数组下标 |
| O(log n) | 对数 | 二分查找、堆操作 |
| O(n) | 线性 | 单次遍历 |
| O(n log n) | 线性对数 | 快排、归并、堆排序 |
| O(n²) | 平方 | 双层循环、冒泡 |
| O(2ⁿ) | 指数 | 朴素递归斐波那契 |

**空间复杂度**：辅助数组/哈希表通常 O(n)；原地操作 O(1)。

## 二、题型模板

### 2.1 双指针

**适用**：有序数组、链表、去重、滑动窗口。

```javascript
// 两数之和（有序数组）
function twoSumSorted(nums, target) {
  let l = 0, r = nums.length - 1;
  while (l < r) {
    const sum = nums[l] + nums[r];
    if (sum === target) return [l, r];
    if (sum < target) l++;
    else r--;
  }
  return [];
}
// 时间 O(n)，空间 O(1)
```

### 2.2 滑动窗口

**适用**：子串/子数组最值、满足条件的最短窗口。

```javascript
function lengthOfLongestSubstring(s) {
  const map = new Map();
  let max = 0, left = 0;
  for (let right = 0; right < s.length; right++) {
    const ch = s[right];
    if (map.has(ch) && map.get(ch) >= left) {
      left = map.get(ch) + 1;
    }
    map.set(ch, right);
    max = Math.max(max, right - left + 1);
  }
  return max;
}
// 时间 O(n)，空间 O(min(n, charset))
```

### 2.3 二分查找

**适用**：有序数组、旋转数组、答案二分（最小满足条件的值）。

```javascript
function binarySearch(nums, target) {
  let lo = 0, hi = nums.length - 1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    if (nums[mid] === target) return mid;
    if (nums[mid] < target) lo = mid + 1;
    else hi = mid - 1;
  }
  return -1;
}
```

### 2.4 链表

```javascript
// 反转链表
function reverseList(head) {
  let prev = null, cur = head;
  while (cur) {
    const next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
  }
  return prev;
}

// 快慢指针判环
function hasCycle(head) {
  let slow = head, fast = head;
  while (fast?.next) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) return true;
  }
  return false;
}
```

### 2.5 树（DFS / BFS）

```javascript
// 前序 DFS
function preorder(root, res = []) {
  if (!root) return res;
  res.push(root.val);
  preorder(root.left, res);
  preorder(root.right, res);
  return res;
}

// 层序 BFS
function levelOrder(root) {
  if (!root) return [];
  const queue = [root], res = [];
  while (queue.length) {
    const level = [];
    const size = queue.length;
    for (let i = 0; i < size; i++) {
      const node = queue.shift();
      level.push(node.val);
      if (node.left) queue.push(node.left);
      if (node.right) queue.push(node.right);
    }
    res.push(level);
  }
  return res;
}
```

### 2.6 动态规划

**步骤**：定义状态 → 转移方程 → 初始条件 → 遍历顺序 → 优化空间。

```javascript
// 爬楼梯：dp[i] = dp[i-1] + dp[i-2]
function climbStairs(n) {
  if (n <= 2) return n;
  let a = 1, b = 2;
  for (let i = 3; i <= n; i++) {
    [a, b] = [b, a + b];
  }
  return b;
}
// 时间 O(n)，空间 O(1)
```

### 2.7 排序

```javascript
// 快排（面试常考）
function quickSort(arr, lo = 0, hi = arr.length - 1) {
  if (lo >= hi) return arr;
  const p = partition(arr, lo, hi);
  quickSort(arr, lo, p - 1);
  quickSort(arr, p + 1, hi);
  return arr;
}
function partition(arr, lo, hi) {
  const pivot = arr[hi];
  let i = lo;
  for (let j = lo; j < hi; j++) {
    if (arr[j] < pivot) [arr[i], arr[j]] = [arr[j], arr[i]], i++;
  }
  [arr[i], arr[hi]] = [arr[hi], arr[i]];
  return i;
}
// 平均 O(n log n)，最坏 O(n²)

// 归并排序（稳定）
function mergeSort(arr) {
  if (arr.length <= 1) return arr;
  const mid = arr.length >> 1;
  return merge(mergeSort(arr.slice(0, mid)), mergeSort(arr.slice(mid)));
}
function merge(a, b) {
  const res = []; let i = 0, j = 0;
  while (i < a.length && j < b.length) res.push(a[i] <= b[j] ? a[i++] : b[j++]);
  return res.concat(a.slice(i), b.slice(j));
}
// 时间 O(n log n)，空间 O(n)，稳定

// 堆排序
function heapSort(arr) {
  const n = arr.length;
  const heapify = (i, size) => {
    let largest = i, l = 2 * i + 1, r = 2 * i + 2;
    if (l < size && arr[l] > arr[largest]) largest = l;
    if (r < size && arr[r] > arr[largest]) largest = r;
    if (largest !== i) { [arr[i], arr[largest]] = [arr[largest], arr[i]]; heapify(largest, size); }
  };
  for (let i = (n >> 1) - 1; i >= 0; i--) heapify(i, n);
  for (let end = n - 1; end > 0; end--) {
    [arr[0], arr[end]] = [arr[end], arr[0]];
    heapify(0, end);
  }
  return arr;
}
// 时间 O(n log n)，空间 O(1)，不稳定
```

### 排序算法对比

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|
| 快排 | O(n log n) | O(n²) | O(log n) | 否 |
| 归并 | O(n log n) | O(n log n) | O(n) | 是 |
| 堆排 | O(n log n) | O(n log n) | O(1) | 否 |
| 冒泡 | O(n²) | O(n²) | O(1) | 是 |

### 2.8 堆 / 优先队列（手写）

```javascript
class MinHeap {
  constructor() { this.heap = []; }
  push(val) {
    this.heap.push(val);
    this._up(this.heap.length - 1);
  }
  pop() {
    if (!this.heap.length) return null;
    const top = this.heap[0];
    const last = this.heap.pop();
    if (this.heap.length) { this.heap[0] = last; this._down(0); }
    return top;
  }
  _up(i) {
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (this.heap[p] <= this.heap[i]) break;
      [this.heap[p], this.heap[i]] = [this.heap[i], this.heap[p]];
      i = p;
    }
  }
  _down(i) {
    const n = this.heap.length;
    while (true) {
      let smallest = i, l = 2 * i + 1, r = 2 * i + 2;
      if (l < n && this.heap[l] < this.heap[smallest]) smallest = l;
      if (r < n && this.heap[r] < this.heap[smallest]) smallest = r;
      if (smallest === i) break;
      [this.heap[i], this.heap[smallest]] = [this.heap[smallest], this.heap[i]];
      i = smallest;
    }
  }
}
// push/pop O(log n)，适用：前 K 大、合并 K 路有序流
```

### 2.9 Trie 前缀树

```javascript
class TrieNode { constructor() { this.children = {}; this.isEnd = false; } }
class Trie {
  constructor() { this.root = new TrieNode(); }
  insert(word) {
    let node = this.root;
    for (const ch of word) {
      node.children[ch] ??= new TrieNode();
      node = node.children[ch];
    }
    node.isEnd = true;
  }
  search(word) {
    const node = this._walk(word);
    return !!node?.isEnd;
  }
  startsWith(prefix) { return !!this._walk(prefix); }
  _walk(str) {
    let node = this.root;
    for (const ch of str) {
      if (!node.children[ch]) return null;
      node = node.children[ch];
    }
    return node;
  }
}
// 适用：自动补全、敏感词过滤、IP 路由
```

### 2.10 并查集（Union-Find）

```javascript
class UnionFind {
  constructor(n) {
    this.parent = Array.from({ length: n }, (_, i) => i);
    this.rank = Array(n).fill(0);
  }
  find(x) {
    if (this.parent[x] !== x) this.parent[x] = this.find(this.parent[x]);
    return this.parent[x];
  }
  union(a, b) {
    const ra = this.find(a), rb = this.find(b);
    if (ra === rb) return false;
    if (this.rank[ra] < this.rank[rb]) this.parent[ra] = rb;
    else if (this.rank[ra] > this.rank[rb]) this.parent[rb] = ra;
    else { this.parent[rb] = ra; this.rank[ra]++; }
    return true;
  }
}
// 近乎 O(1)，适用：连通分量、最小生成树 Kruskal、岛屿数量变种
```

### 2.11 图与拓扑排序

```javascript
// 邻接表 + BFS 拓扑排序（Kahn）
function topoSort(n, edges) {
  const indeg = Array(n).fill(0), adj = Array.from({ length: n }, () => []);
  for (const [u, v] of edges) { adj[u].push(v); indeg[v]++; }
  const queue = [];
  indeg.forEach((d, i) => d === 0 && queue.push(i));
  const order = [];
  while (queue.length) {
    const u = queue.shift();
    order.push(u);
    for (const v of adj[u]) if (--indeg[v] === 0) queue.push(v);
  }
  return order.length === n ? order : []; // 空数组表示有环
}
// 时间 O(V+E)，适用：任务调度、依赖解析、课程表
```

## 三、字节 hard 高频（架构师二面）

### 3.1 接雨水（双指针）

```javascript
function trap(height) {
  let l = 0, r = height.length - 1, lMax = 0, rMax = 0, water = 0;
  while (l < r) {
    if (height[l] < height[r]) {
      lMax = Math.max(lMax, height[l]);
      water += lMax - height[l++];
    } else {
      rMax = Math.max(rMax, height[r]);
      water += rMax - height[r--];
    }
  }
  return water;
}
// 时间 O(n)，空间 O(1)
```

### 3.2 最长递增子序列（LIS）

```javascript
function lengthOfLIS(nums) {
  const tails = [];
  for (const n of nums) {
    let lo = 0, hi = tails.length;
    while (lo < hi) {
      const mid = (lo + hi) >> 1;
      if (tails[mid] < n) lo = mid + 1; else hi = mid;
    }
    tails[lo] = n;
  }
  return tails.length;
}
// 时间 O(n log n)，Vue3 Diff 也用 LIS 思想
```

### 3.3 编辑距离

```javascript
function minDistance(word1, word2) {
  const m = word1.length, n = word2.length;
  const dp = Array.from({ length: m + 1 }, () => Array(n + 1).fill(0));
  for (let i = 0; i <= m; i++) dp[i][0] = i;
  for (let j = 0; j <= n; j++) dp[0][j] = j;
  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (word1[i - 1] === word2[j - 1]) dp[i][j] = dp[i - 1][j - 1];
      else dp[i][j] = 1 + Math.min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]);
    }
  }
  return dp[m][n];
}
// 时间 O(mn)，空间可优化到 O(n)
```

### 3.4 最长回文子串（中心扩展）

```javascript
function longestPalindrome(s) {
  let start = 0, maxLen = 1;
  const expand = (l, r) => {
    while (l >= 0 && r < s.length && s[l] === s[r]) { l--; r++; }
    if (r - l - 1 > maxLen) { start = l + 1; maxLen = r - l - 1; }
  };
  for (let i = 0; i < s.length; i++) { expand(i, i); expand(i, i + 1); }
  return s.slice(start, start + maxLen);
}
// 时间 O(n²)，Manacher 可 O(n)
```

## 五、答题骨架（面试现场）

1. **澄清**：输入规模、边界、是否有序、能否改原数组
2. **暴力**：先说 O(n²) 思路，证明你会做
3. **优化**：指出瓶颈，给出更优方案与复杂度
4. **编码**：变量命名清晰，边界处理完整

## 六、手写 LRU（架构师高频）

```javascript
class LRUCache {
  constructor(capacity) {
    this.cap = capacity;
    this.map = new Map(); // Map 保持插入顺序
  }
  get(key) {
    if (!this.map.has(key)) return -1;
    const val = this.map.get(key);
    this.map.delete(key);
    this.map.set(key, val); // 移到末尾（最近使用）
    return val;
  }
  put(key, value) {
    if (this.map.has(key)) this.map.delete(key);
    this.map.set(key, value);
    if (this.map.size > this.cap) {
      const oldest = this.map.keys().next().value;
      this.map.delete(oldest);
    }
  }
}
// get/put 均摊 O(1)
```

## 面试高频问答（追问链）

> 大厂对一个考点通常追问到能力边界：**概念 → 机制 → 边界 → ⭐ 原理（触底）→ 实战（落地）**。实战层是区分「背过」和「做过」的关键。算法题会从暴力追到最优复杂度。

### 链一：LRU 缓存（高频手撕）

1. **概念**：LRU 是什么？→ 最近最少使用淘汰策略。
2. **机制**：为什么用 Map + 双向链表？→ Map O(1) 查、链表 O(1) 移动/删除。
3. **边界**：get 和 put 复杂度？→ 均摊 O(1)。
4. **应用**：JS 怎么简化？→ Map 本身有序，删除后重新 set 即移到末尾。
5. ⭐ **原理（触底）**：LFU 和 LRU 区别？怎么实现 O(1) 的 LFU？→ LFU 按频次淘汰；用「频次→双向链表」哈希 + 最小频次指针实现 O(1)。
6. **实战（落地）**：白板写 LRU 怎么拿分？→ 先说 Map+链表思路；写 get/put 均 O(1)；主动说边界（容量 0、更新已存在 key）；写完报复杂度并跑 2 个用例。

### 链二：排序

1. **概念**：快排思路？→ 选 pivot 分治。
2. **边界**：最坏情况？→ 有序 + 固定 pivot 退化 O(n²)。
3. **应用**：怎么优化？→ 随机/三数取中 pivot、小数组插入排序。
4. ⭐ **原理（触底）**：哪些排序稳定？V8 的 Array.sort 用什么？→ 归并/插入稳定，快/堆不稳定；V8 用 TimSort（归并+插入，稳定）。
5. **实战（落地）**：手撕快排怎么口述？→ 先讲分治 + pivot 选法；写 partition；说最坏 O(n²) 和随机 pivot 优化；写完用 [3,1,2] 走一遍，主动报时空复杂度。

### 链三：图与拓扑

1. **概念**：拓扑排序解决什么？→ 有依赖的执行顺序。
2. **机制**：怎么判断有环？→ BFS 入度法，order 长度 < V 即有环；或 DFS 三色标记。
3. **应用**：前端哪里用？→ 任务依赖、模块加载、低代码组件依赖。
4. ⭐ **原理（触底）**：并查集路径压缩 + 按秩合并为什么近 O(1)？→ 压缩把节点直接挂根降树高，按秩合并控制高度，均摊复杂度趋于反阿克曼函数 α(n)。
5. **实战（落地）**：拓扑排序题怎么答？→ 先说 BFS 入度法；写完后检查 order.length === n 判环；结合前端场景（任务依赖 DAG）一句话落地，体现不只是刷题。
